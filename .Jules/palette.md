## 2026-07-17 - Accessible Confirmation Dialog for Destructive Actions
**Learning:** Standard browser `window.confirm` dialogs are synchronous, block the main JavaScript execution thread, and cannot be custom-styled or given proper accessible focus management. Replacing them with a Radix UI `Dialog` (with `role="alertdialog"`) manages keyboard trapping and Escape key closing natively. Incorporating React 19's `useTransition` allows asynchronous backend operations to run smoothly with real-time UI loading indicators on the confirmation button, enhancing perceived performance and visual delight.
**Action:** Always replace synchronous `window.confirm` calls with a modular `ConfirmDialog` backed by Radix UI, wrapping server-side triggers in a transition state to show micro-loading indicators.
