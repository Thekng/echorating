## 2026-08-07 - Custom Modal ConfirmDialog vs window.confirm
**Learning:** Browser-blocking native functions like `window.confirm` block the main thread and degrade the perceived quality of the user experience. Replacing them with accessible, animated modal dialogs (using Radix UI Dialog primitives with an ARIA `alertdialog` role) improves both styling consistency and screen reader compatibility. Additionally, under React's `useTransition`, asynchronous operations (like server actions) must be executed in a synchronous block with chained promise handlers to avoid TransitionFunction type mismatch errors under React 18/19.
**Action:** When performing destructive actions or confirmations, always prefer the accessible `ConfirmDialog` wrapper over native dialogue windows, handle loading states with non-blocking transition states, and reset deletion tracking states in a `.finally()` promise chain.
