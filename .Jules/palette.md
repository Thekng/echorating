## 2026-08-05 - Replacing window.confirm with Custom Accessible Dialog
**Learning:** Browser native window.confirm blocks the main JavaScript execution thread, resulting in abrupt, non-native visual states that degrade UX. Replacing it with a custom Radix UI Dialog-based ConfirmDialog improves keyboard navigation, supports screen reader accessibility (via alertdialog role), and adds pleasant zoom/fade-in animations. In a controlled dialog, desynchronization of the open state during default backdrop clicks or Escape press dismissal must be prevented by wiring the onOpenChange prop to reset selection state.
**Action:** Always replace thread-blocking native confirm alerts with accessible Radix UI Dialog components, ensuring that local trigger state is cleanly reset via the onOpenChange and onCancel hooks.
